# 📊 Contable Andina – Sitio web corporativo

Sitio web para una firma de asesoría contable y tributaria (proyecto demo de portafolio).

🔗 **Ver en vivo:** https://contable-andina-lina.netlify.app

## Características

- Diseño sobrio y profesional, pensado para servicios contables
- Diseño responsive con menú desplegable para celular
- Sección de servicios con íconos (Lucide)
- Preguntas frecuentes desplegables (acordeón con JavaScript)
- Formulario de contacto que arma el mensaje y lo envía por WhatsApp
- Animaciones suaves al desplazarse (Intersection Observer)
- Pie de página con columnas de navegación y contacto

## Tecnologías

- HTML5
- CSS3 (Flexbox, Grid, variables CSS, media queries)
- JavaScript
- Lucide Icons y Google Fonts
- Publicado en Netlify
